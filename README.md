# Controle de Insumos - Widmen Autocenter

Sistema de controle de entrada e saída de insumos para 8 filiais.

## Stack
- Frontend: React + Vite (PWA)
- Backend: Node.js + Express
- Banco de dados: Google Sheets API

## Estrutura
- /frontend — interface React
- /backend — API Node.js

## Configuração
1. Copie o `.env.example` para `.env`
2. Preencha as variáveis de ambiente
3. Consulte a documentação de cada pasta
